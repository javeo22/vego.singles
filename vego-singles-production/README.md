# Vego Singles

Production starter for Vercel + Supabase.

## Deploy
1. Copy project into the connected GitHub repository.
2. Ensure Vercel has the variables from `.env.example` plus the variables generated by the Supabase integration.
3. Run `supabase/migrations/202607300001_initial_schema.sql` in the Supabase SQL Editor.
4. Run `supabase/seed_initial_inventory.sql` in the SQL Editor.
5. Deploy through GitHub/Vercel.
6. In Supabase Auth URL settings, set `https://vego-singles.vercel.app` and allow `/auth/callback`.

All imported inventory begins unpublished and with language `unknown` and location `UNASSIGNED`.
